# NEON ARENA

모바일 우선 브라우저 생존 슈팅 게임입니다. 설치 없이 브라우저에서 바로 플레이합니다.

▶ 플레이: https://das-ops9.github.io/neon-arena/

- 끝없는 생존, 원하는 때 직접 올리는 Stage, Point TOP 3
- 6개 모드, 3개 기체, 공통 스킬트리, 10분 포위, 슈퍼코인 특수 출격
- 기록과 재화는 이 기기의 브라우저에만 저장됩니다. 다른 기기로 옮길 때는 기록 탭의 백업을 쓰세요.

조작: 빈 화면을 터치해 이동하고 대시·충격파·Stage 버튼을 누릅니다. 키보드는 WASD·방향키, Space, E, U, Esc입니다.

버전 4.0.0 · 이 저장소에는 배포 파일만 있습니다. 사용한 외부 라이브러리의 라이선스는 LICENSES.txt에 있습니다.
